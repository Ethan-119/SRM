供应商资质等级标准
供应商资质等级分为三级：
一级供应商：具备ISO 9001质量管理体系认证、ISO 14001环境管理体系认证，注册资本5000万元以上，年营业额1亿元以上，同行业服务经验5年以上。一级供应商可承接核心物料的供应。
二级供应商：具备ISO 9001质量管理体系认证，注册资本1000万元以上，年营业额3000万元以上，同行业服务经验3年以上。二级供应商可承接非核心物料和辅助物料的供应。
三级供应商：具备基本工商注册资质，注册资本100万元以上，同行业服务经验1年以上。三级供应商仅可承接低值易耗品和通用物料。

供应商评估方法
供应商评估采用综合评分法，从以下五个维度进行打分（每项20分，满分100分）：
1. 价格竞争力（20分）：报价与市场平均价的偏离程度，低于平均价5%以上得满分，高于平均价10%以上不得分。
2. 质量水平（20分）：产品合格率、质量体系认证、历史退货率综合评估。
3. 交付能力（20分）：准时交付率、产能弹性、物流覆盖范围。
4. 技术能力（20分）：研发投入比例、专利数量、技术团队规模。
5. 服务响应（20分）：售后响应时间、问题处理效率、客户满意度评分。
总分>=85分为优秀，70-84分为良好，60-69分为合格，<60分不合格。

询比价流程规范
标准询比价流程包含以下步骤：
1. 需求确认：明确物料名称、规格、数量、质量要求、预算上限、期望交期。
2. 供应商筛选：根据物料品类、供应商资质等级、合作状态、所在地区进行硬过滤，选出3-5家候选供应商。
3. 发送询价：向候选供应商发送询价单，包含物料规格、数量、交期要求。
4. 报价收集：在规定时间内收集各供应商报价，包含单价、最小起订量、交期、付款条件。
5. 比价分析：进行多维度综合比较，不能仅看单价，需考虑：
   - 总成本 = 单价 × 数量 + 运费 - 阶梯折扣
   - 交期是否满足需求
   - 供应商当前合作状态和资质等级
   - 历史合作质量和交付记录
6. 推荐决策：输出推荐供应商排序及理由，提交人工审核确认。
7. 结果归档：将询比价过程和决策理由归档，形成审计日志。

供应商状态管理
供应商生命周期状态包括：
0-注册：供应商在线注册，填写基本信息。
1-待审核：采购部门对供应商资质进行审核。
2-已准入：审核通过，进入合格供应商名录。
3-合作中：有实际采购合作关系的活跃供应商。
4-冻结：因质量、交付等问题被暂停合作的供应商。
5-黑名单：因严重违规被永久禁止合作的供应商。

状态流转规则：
- 0→1：供应商提交注册申请后自动进入待审核
- 1→2：审核通过，采购部门确认准入
- 1→5：审核不通过，存在虚假信息时拉黑
- 2→3：首次合作订单签订后进入合作中
- 3→4：出现质量问题或交付违约时冻结
- 4→3：问题整改通过后恢复合作
- 4→5：严重违规或多次整改不合格拉入黑名单
注意：禁止越级状态变更。

采购订单管理
采购订单状态流转：
待确认 → 生产中 → 已发货 → 已签收
每个状态变更都需要对应的业务凭证：
- 待确认→生产中：供应商确认函
- 生产中→已发货：发货通知单和物流凭证
- 已发货→已签收：收货确认单和质检报告

采购成本管理
采购总成本构成：
1. 直接成本：物料单价 × 采购数量
2. 物流成本：运输费用、保险费用
3. 税费：增值税、关税（进口物料）
4. 管理成本：采购部门人力成本分摊
5. 阶梯折扣：根据采购数量阶梯享受折扣率
   - 采购量>=1000：折扣3%
   - 采购量>=5000：折扣6%
   - 采购量>=10000：折扣10%

供应商风险管控
常见的供应商风险及应对策略：
1. 单一来源风险：核心物料仅有一家供应商，一旦断供影响生产。应对：建立备选供应商库，核心物料至少2家合格供应商。
2. 质量风险：供应商产品质量波动，影响最终产品质量。应对：建立来料检验制度，定期对供应商进行质量审核。
3. 交付风险：供应商交期延误，影响生产计划。应对：合同中明确交期违约责任，建立安全库存机制。
4. 价格风险：原材料价格上涨导致采购成本上升。应对：签订长期框架协议锁定价格，或约定价格调整机制。
5. 合规风险：供应商存在环保、劳动等方面的合规问题。应对：定期对供应商进行合规审查，要求提供合规承诺书。
