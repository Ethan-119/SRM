# SRM 采购流程说明

## 1. 供应商准入流程

1. 供应商在线注册，提交资质材料；
2. 采购部审核资质，质检部审核样品；
3. 提交采购委员会审批，通过进入「已准入」，不通过进入「黑名单」；
4. 准入后进入「合作中」，可参与询比价。

## 2. 询比价（RFQ）流程

1. 采购员通过 AI 采购助手发起正式询价；
2. 系统选定候选供应商并收集报价；
3. AI 完成「评分 + 风险 + 推荐」分析；
4. 采购员确认推荐结果，系统自动生成采购订单。

## 3. 供应商评分维度

| 维度 | 权重 |
|------|------|
| 价格 | 35% |
| 质量 | 25% |
| 交期 | 20% |
| 服务 | 10% |
| 风险 | 10% |

## 4. 资质续期提醒

系统每日凌晨扫描未来 30 天到期资质，通知供应商上传新资质；到期未续期自动冻结供应商。
