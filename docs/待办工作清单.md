## 1. 基础设施搭建（一次性）

### 1.1 已有（确认可用即可）
- PostgreSQL：`srm` 库（业务） + `srm_vector` 库（向量，pgvector）
- Redis（单机，`requirepass=123456`）

### 1.2 Neo4j（新增，必须）
1. 安装 Neo4j（4.4+ 或 5.x，桌面版或 Docker 均可）。
2. 创建一个名为 **`SRM`** 的数据库（`application.yml` 默认 `NEO4J_DATABASE=SRM`）。
3. 用 Neo4j Browser / cypher-shell 依次执行：
   - `src/main/resources/graph/schema.cypher`（约束 + 索引）
   - `src/main/resources/graph/seed.cypher`（演示节点 + 关系，已对齐业务库供应商 ID）

### 1.3 PostgreSQL + pgvector（新增，必须）
1. 安装 PostgreSQL（14+），并确认可创建 `vector` 扩展。
2. 创建两个库：
   ```bash
   createdb srm
   createdb srm_vector
   ```
3. 向量库建表 + 建索引（脚本已提供 `sql/pgvector.sql`）：
   ```bash
   psql -d srm_vector -f sql/pgvector.sql
   ```
   > 向量维度 1024，对应 `text-embedding-v4` 输出；如需改动，同步 `application.yml` 的 `srm.pgvector.dimension`。

### 1.4 DashScope API Key（必须）
- 申请通义千问 API Key，用于 chat（`qwen3-max`）与 embedding（`text-embedding-v4`）。

## 3. 数据对齐（已解决，仅需按上面顺序执行）

### 3.1 Neo4j ↔ PostgreSQL 供应商 ID
- `seed.cypher` 已改为使用业务库真实供应商 ID 与名称（`srm_supplier.id` 1~45 中的子集：1/2/7/15/22/23/24/39）。
- 图谱的关联风险、集中度、资质到期校验都按 `Supplier.id` 关联，与业务库一致。

### 3.2 资质「30 天内到期」造数
- seed 中 `#2 上海宝钢` 的 `ISO9001-A` 有效期设为 `2026-10-20`（相对 2026-09-30 落在 30 天内），会触发续期扫描；
- `#15 济南钢铁` 的 `ISO9001-C` 已过期（`2025-06-30`），用于验证过期过滤。
- 若日期已推进，把 `expireDate` 改到未来 30 天内即可：
  ```cypher
  MATCH (c:Cert {certNo:'ISO9001-A'}) SET c.expireDate = '2026-10-15';
  ```

## 5. 重启应用并验证

重启 Spring Boot（使 `@EnableScheduling` / `@EnableAsync` 生效）。

### 5.1 询比价闭环
```bash
# 创建询比价单（3 家冷轧钢板供应商）
curl -X POST http://localhost:8083/api/rfq \
  -H 'Content-Type: application/json' \
  -d '{"materialName":"冷轧钢板","quantity":500,"supplierIds":[2,15,23],"quoteHours":24}'

# 供应商报价（3 家分别）
curl -X POST http://localhost:8083/api/rfq/quote \
  -H 'Content-Type: application/json' \
  -d '{"rfqId":<id>,"supplierId":2,"price":8500,"taxRate":0.13,"deliveryDays":15}'

# 手动触发分析
curl -X POST http://localhost:8083/api/rfq/<id>/analyze

# 查看结果
curl http://localhost:8083/api/rfq/<id>

# 确认下单
curl -X POST http://localhost:8083/api/rfq/<id>/confirm \
  -H 'Content-Type: application/json' \
  -d '{"managerId":1,"approved":true,"comment":""}'
```

### 5.2 资质续期
```bash
curl -X POST "http://localhost:8083/api/cert/review?supplierId=2&certType=ISO9001&certNo=ISO9001-A&newExpireDate=2027-12-31"
```

### 5.3 混合检索 RAG
```bash
curl "http://localhost:8083/api/rag/search?query=冷轧钢板价格最低的供应商&topK=5"
```
> 前提：2.2 的向量数据已灌入，3.1 的图谱 ID 已对齐。

### 5.4 RAG 评估（可选）
- 测试类：`RagEvalTest`、`RagMetricsCalculatorTest`（依赖 pgvector + Neo4j + 数据就绪）。
- 运行 `mvn -Dtest=RagEvalTest test`，检查 `recall / precision / MRR / nDCG`。

### 5.5 内生 Agent
```bash

  -H 'Content-Type: application/json' \
  -d '{"query":"帮我查冷轧钢板最低价供应商","sessionId":"demo"}'
```
